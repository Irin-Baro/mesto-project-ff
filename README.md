## Описание <a id=description></a>

Проект Mesto позволяет пользователям:
  - добавлять карточки и превью фотографии на страницу;
  - удалять карточки по клику на иконку урны;
  - ставить лайк на карточке;
  - редактировать профиль пользователя

## Установка и запуск проекта <a id=run></a>
    
```sh
git clone https://github.com/Irin-Baro/mesto-project-ff
```

```sh
cd mesto-project-ff
```

```sh
npm install
```

```sh
npm run dev (npm run build)
```
